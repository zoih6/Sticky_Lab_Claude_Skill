# Sticky Lab — Quality and Consistency Checklist

Before delivery, verify each item.

## Visual identity
- [ ] Cream notebook/paper world is clear.
- [ ] Core colors match the palette: `#FFF4DF`, `#FFD84D`, `#FF783E`, `#25231F`.
- [ ] Paper is matte, layered, and subtly textured.
- [ ] Marker outlines and sticker borders use consistent weight.
- [ ] Supporting colors are limited and justified.
- [ ] No unexplained shift to neon, gradients, glossy 3D, or generic templates.
- [ ] Supplied references guide the style without forcing every scene to copy the same layout.

## Script and voice
- [ ] Narration wording is preserved unless rewriting was requested.
- [ ] Each scene communicates the phrase or idea currently being spoken.
- [ ] Exact on-screen text is separate from voiceover text.
- [ ] Audio duration and timing confidence are stated honestly.
- [ ] No invented precise timestamps.

## Motion and edit
- [ ] Each scene has one main motion event.
- [ ] Every moving element has a clear start and end state.
- [ ] No constant jitter or meaningless zooms.
- [ ] Transitions feel like actions in one paper world.
- [ ] Text remains readable long enough.
- [ ] Sound effects are restrained and useful.

## Technical and delivery
- [ ] 9:16 vertical, 1080 × 1920, 30 fps unless user specifies otherwise.
- [ ] Safe margins protect text from platform UI.
- [ ] Asset list distinguishes supplied, generated, and missing assets.
- [ ] Final render is not claimed unless it exists.
- [ ] Deliver prompts, scene map, and export notes in a usable structure.
