# Sticky Lab — Visual Style Bible

## 1. Identity in one sentence
A playful, tactile explainer reel that feels like a real cream notebook covered with yellow sticky notes, orange paper accents, black-marker doodles, and hand-placed cut-paper stickers.

## 2. Palette
| Token | Hex | Role |
|---|---|---|
| Paper Cream | `#FFF4DF` | Main notebook/background |
| Sticky Yellow | `#FFD84D` | Primary attention surface |
| Marker Orange | `#FF783E` | Secondary emphasis / important reveal |
| Ink Black | `#25231F` | Main outlines, text, doodles |
| Paper White | `#FFFEF8` | Note surfaces and sticker borders |
| Kraft Brown | `#B58A60` | Tape/cardboard accents |
| Warm Gray | `#D9D1C3` | Subtle paper shadows and secondary layers |

### Color proportion
As a starting point per scene: 60% cream/paper neutrals, 20% yellow, 10% black/ink, 10% orange. This is a guideline, not a requirement to force every color into every frame. White, kraft, and warm gray are supporting materials.

### Contrast
- Use ink black for legible copy.
- Orange is an accent, not a full-scene background by default.
- Yellow notes should remain distinguishable from cream paper.
- Keep small text away from busy paper texture.

## 3. Material and surface
- Matte paper, faint paper fibers, slight natural irregularity.
- Sticky-note corners may curl subtly; paper edges may be torn or cut.
- Tape is pale cream/yellow masking tape with a faint translucent quality.
- Layered paper casts soft contact shadows consistent with one light direction.
- Texture is restrained. Do not overlay strong grain on every object.

## 4. Illustration language
- Hand-drawn black-marker doodles, arrows, circles, underlines, stars, ticks, question marks, and simple explanatory icons.
- Icons are simplified and slightly irregular, with bold black outlines.
- Sticker assets may use a thick off-white outer border and a narrow dark outline, following the uploaded style sheets.
- Use yellow and orange as the main icon fills. Small blue or pink accents may appear only when a supplied reference asset explicitly contains them or when the user approves an expanded palette; they are not part of the default core palette.
- Use metaphors that clarify the subject. Examples: brain + scattered notes for forgetting; router + connected devices for Wi-Fi; a globe/network/cloud for the internet.
- Avoid unrelated cute mascots unless the user requests them. The supplied doodle sheet is a reference for line weight and sticker treatment, not a requirement to use its specific characters.

## 5. Typography
- Arabic: Cairo ExtraBold/Bold for headings; Tajawal Bold/Medium for supporting copy.
- English/numbers: bold, rounded, highly legible display type that harmonizes with the marker illustration. Use actual font assets in the render rather than drawing final text in image generation.
- Handwritten annotation can be simulated with a suitable handwriting font or drawn path, but reserve it for tiny annotations, not paragraphs.
- Keep copy short. Prefer one headline or phrase per note.
- Preserve Arabic spelling, punctuation, RTL order, and diacritics exactly as supplied unless editing is requested.
- Never mirror Arabic text or rely on generative image text for final legibility.

## 6. Composition
- The overall world feels like a notebook or worktable, but scene layouts should vary.
- Combine one primary visual metaphor with a small number of supporting notes, doodles, and labels.
- Establish hierarchy: headline/hero object first, supporting explanation second, decorative marks last.
- Leave breathing room; do not fill every gap with stickers.
- Keep important text inside a conservative mobile safe area.
- Avoid repeating a centered note card in every scene. Alternate between pinned note, torn-paper reveal, diagram, split comparison, stacked layers, and close-up detail while preserving the same materials.

## 7. Reference-sheet usage
Three supplied sheets are included:
- `assets/reference-sheets/sticky-lab-style-reference.png`: primary guide for paper notes, tape, black outlines, white sticker borders, and yellow/cream contrast.
- `assets/reference-sheets/paper-assets-sheet.png`: guide for note shapes, tape, torn edges, and paper silhouettes.
- `assets/reference-sheets/doodle-icons-sheet.png`: guide for marker doodles, icon outline weight, sticker cutline, and visual playfulness.

The supplied sheets include some black backgrounds and extra accent colors. Treat these as asset-sheet presentation choices, not as the required video background or complete palette. The finished video should use the cream notebook world unless the user explicitly requests a black-background sticker montage.

## 8. Style lock phrase
Include this compact style lock in each scene prompt:
“Sticky Lab visual identity: warm cream notebook surface, matte paper layers, yellow sticky notes and restrained orange accents, thick hand-drawn black-marker outlines, off-white sticker cutlines, subtle contact shadows, tactile paper-cut construction, clean hierarchy, consistent line weight and material treatment.”
