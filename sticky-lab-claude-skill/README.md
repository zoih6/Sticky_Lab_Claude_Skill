# Sticky Lab Claude Skill

## Contents
- `SKILL.md`: main instructions Claude follows.
- `references/`: visual identity, motion language, voiceover/script workflow, QA checklist.
- `templates/SCENE_PLAN_TEMPLATE.md`: reusable production-plan template.
- `assets/reference-sheets/`: the three supplied visual reference sheets.

## Install
1. Keep the ZIP structure intact and upload it through Claude's Skills interface using the available create/upload skill flow.
2. Enable the skill after upload.
3. Test with a 15-second script and then a different topic. Compare palette, materials, outlines, and motion language.
4. If Claude only returns a plan, connect/use a video generation or editing tool separately; the skill itself does not render video.

## Suggested test prompt
“Use Sticky Lab to plan a 15-second vertical reel explaining why we forget information quickly. Use the attached voiceover if provided. Give me measured timings only if you can analyze the audio; otherwise label them estimates. Return the scene map, per-scene visual and animation prompts, exact overlay copy, and asset manifest.”
